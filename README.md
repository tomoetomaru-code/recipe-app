# 🍳 マイレシピ帳 — セットアップ手順

## 必要なもの
- GitHubアカウント（すでにお持ち）
- Vercelアカウント（すでにお持ち）
- Googleアカウント（Googleスプレッドシート用）

---

## STEP 1：GitHubにリポジトリを作る

1. [github.com](https://github.com) を開いてログイン
2. 右上の「＋」→「New repository」をクリック
3. Repository name に `recipe-app`（何でもOK）と入力
4. 「Create repository」をクリック
5. 作成されたページで「uploading an existing file」をクリック
6. 以下の2ファイルをドラッグ＆ドロップ
   - `index.html`
   - `code.gs`
7. 「Commit changes」をクリック

---

## STEP 2：VercelでアプリをURLに公開する

1. [vercel.com](https://vercel.com) を開いてログイン
2. 「Add New…」→「Project」をクリック
3. GitHubと連携して、`recipe-app` リポジトリを選択
4. 設定はそのまま「Deploy」をクリック
5. 数秒でデプロイ完了！`https://recipe-app-xxxx.vercel.app` のようなURLが発行される

> このURLをLINEでお友達に送れば、すぐに使ってもらえます 🎉

---

## STEP 3：Googleスプレッドシートを設定する

### 3-1. スプレッドシートを作成
1. [sheets.google.com](https://sheets.google.com) を開く
2. 「＋ 新しいスプレッドシート」をクリック
3. タイトルは何でもOK（例：「レシピデータベース」）

### 3-2. Apps Script を設定
1. メニューの「拡張機能」→「Apps Script」を開く
2. 最初から書いてあるコードを**すべて削除**する
3. `code.gs` の内容を**コピー&ペースト**して貼り付ける
4. 「保存」（Ctrl+S または ⌘+S）をクリック

### 3-3. デプロイする（URLを発行する）
1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコン⚙️をクリックして「ウェブアプリ」を選択
3. 設定を以下のように変更：
   - 説明：`レシピアプリ`（何でもOK）
   - ユーザーとして実行：`自分`
   - アクセスできるユーザー：**「全員」**（ここが重要！）
4. 「デプロイ」をクリック
5. Googleアカウントの承認を求められたら「許可」する
6. 「ウェブアプリのURL」をコピーする

---

## STEP 4：アプリとスプレッドシートをつなぐ

1. VercelのURL（例：`https://recipe-app-xxxx.vercel.app`）をスマホやPCで開く
2. 下のメニューの「⚙️設定」をタップ
3. 「スプレッドシートAPIのURL」にコピーしたURLを貼り付ける
4. 「接続テスト & 保存」をタップ
5. 「✅ 接続成功！」と表示されれば完了！

---

## 使い方

| 操作 | 方法 |
|------|------|
| レシピを探す | 上の検索バーに料理名・食材を入力 |
| カテゴリで絞り込む | 検索バー下のカテゴリをタップ |
| レシピを見る | カードをタップ |
| レシピを追加 | 下の「➕レシピ追加」をタップ |
| レシピを編集 | 詳細画面の「✏️編集」をタップ |
| レシピを削除 | 詳細画面の「🗑️削除」をタップ |

---

## お友達への渡し方

VercelのURL（例：`https://recipe-app-xxxx.vercel.app`）をLINEで送るだけです。

お友達は：
1. URLをスマホで開く
2. ⚙️設定から**自分のスプレッドシートのURL**を入力する
3. それぞれが独自のレシピを管理できます

---

## データを直接確認・編集する

Googleスプレッドシートを開くと、登録したレシピが一覧で確認できます。
シートを直接編集することも可能です（ただし`id`列は変更しないでください）。

---

## トラブルシューティング

**接続テストが失敗する場合**
- Apps Scriptのデプロイで「アクセスできるユーザー」が「全員」になっているか確認
- デプロイし直す場合は「新しいデプロイ」から行う（既存のデプロイを更新しない）
- Googleアカウントの承認を忘れていないか確認

**レシピが表示されない場合**
- 設定画面のURLが正しいか確認
- 「接続テスト & 保存」を再度実行する

**code.gsを修正した場合**
- 必ず「新しいデプロイ」から再デプロイする
- 古いURLは使えなくなるので、設定画面で新しいURLに更新する
